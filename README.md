# Learning the C Language

Repositorio com exercecios e atividades que desenvolvi durante a disciplina de **Linguagem de Programação I**, enquanto aprendo a linguagem C.

## Conteudo

Os arquivos `.c` estão organizados por tipo de atividade, como:

- **Listas avaliativas**
- **Atividades de aula**
- **Práticas**
- **Exemplos/teoria vistos em aula**
- **Outros exercicios**

## Como compilar e executar

Os codigos podem ser compilados e executados pelo **Compilai**, ferramenta disponibilizada pela professora para a disciplina.
